# Bubu & Dudu Interactive Birthday Website ❤️

For Mohit Arora from Aastha Sethi Arora — 22 August 2026.

## Customize
Put photos in `assets/photos/` named `photo1.jpg` through `photo14.jpg`.
Put your authorized MP3 at `assets/music/tu-hai-meri.mp3`.
Edit `index.html` for names, dates and messages.

## GitHub Pages
1. Create a public GitHub repository.
2. Upload all contents of this folder.
3. Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main; Folder: /(root).
6. Save.

Your site will be at:
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/

The template uses cute emoji characters as a Bubu & Dudu-inspired placeholder. Replace them with your own licensed character images/GIFs if desired.
